# Tools, MCPs, Plugins and Prompt Operations

Codex is an orchestrator, not a magic account connection. Inspect installed MCP servers, credentials/permissions, tools, schemas and current pricing before use. Never invent tool IDs, links, model names or successful outcomes.

- Higgsfield: browse actual voices and let user select; then generate separate speech tracks after cost/approval check. Verify jobs/status.
- Photo editing: user-authorized private photos, crops/lighting; require consent for changes. Never upload raw identifiable media to this PUBLIC repo.
- Video: combine approved speech, original/licensed music/SFX, captions, graphics and real-foot footage.
- X / FeetFinder: prepare copy; use authorized publishing methods only. No bypassing site policies.
- GitHub: maintain markdown instructions and logs; never commit personal details, media, secrets or EXIF.
- Analytics: log only aggregate metrics or anonymized records.

## Execution checklist
Clarify desired outcome → discover available tools → verify authorization and schemas → distinguish read-only/estimate from paid/publish → show plan/cost and obtain approval → execute once → verify returned IDs/results → log approved decisions.

## Generation prompt template
Output, duration, aspect ratio, subject, shot, setting, tone, palette, delivery, exact script, forbidden elements, privacy, rights and acceptance criteria. Never supply unverified parameters.

## Truthfulness
Never claim connected, generated, published, verified, or saved unless tool output confirms it. Report blockers plainly.
