# Toebe Bryant — Codex Production Headquarters

This is a persistent, local-first Markdown knowledge base for an anonymous basketball-themed adult foot-content brand. It contains a brand pitch, creative direction, launch plans, working copy, audio/video scripts, tool orchestration rules, privacy protections, and logs.

## Quick start
1. Unzip this folder into a private Codex workspace/repository.
2. Open that folder in Codex.
3. Paste the contents of `START_HERE_PROMPT.md` into Codex as the first task.
4. Supply real photos only through an approved private workflow. The images mentioned in the docs are **not included**.
5. Have Codex update `docs/DECISION_LOG.md`, `logs/SESSION_STATE.md`, and `logs/ASSET_MANIFEST.md` after every meaningful session.

## File map
- `AGENTS.md`: mandatory instructions for Codex agents.
- `START_HERE_PROMPT.md`: master kickoff prompt.
- `docs/BRAND_BIBLE.md`: persona, approved copy, constraints.
- `docs/LAUNCH_PLAN.md`: posting, products, pricing experiments, first-week plan.
- `docs/CONTENT_PRODUCTION.md`: photo/video direction and NBA intro.
- `docs/TOOLS_AND_MCP.md`: MCP/plugin orchestration and tool truthfulness.
- `docs/SAFETY_AND_RIGHTS.md`: anonymity, consent, platform/IP precautions.
- `docs/DECISION_LOG.md`: durable decisions and superseded ideas.
- `logs/SESSION_STATE.md`: current work and next steps.
- `logs/ASSET_MANIFEST.md`: media provenance and privacy status.
- `templates/PRODUCTION_BRIEF.md`: reusable creative production form.

## Limits
These files give Codex durable workspace context, not guaranteed memory outside this folder. Codex needs access to this folder and must follow the startup and update instructions. External MCPs, account access, image files, and subscriptions are not automatically included.
